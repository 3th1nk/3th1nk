## 关于我

一名深耕后端多年的开发者，也会上手写 Vue/React 做前端开发（唯独 CSS 依旧时常令人头大）。主力使用 Go 搭建高性能服务，具备 C/C++ 底层开发经验，长期聚焦系统可观测性、自动化运维与云原生领域。

职业生涯起步于硬件驱动开发，之后涉足医疗器械行业，负责心电相关软件研发；再转入物联网行业，参与过扫地机器人、智能音箱等产品开发。2018 年将主力开发语言从 C/C++ 切换为 Go，此后一直做一站式智能运维平台。

近期重点探索大模型在智能运维场景的落地，实践方向覆盖脚本生成、知识库 RAG、告警根因分析、Agent 工作流，边学边试。

个人信条：把重复繁重的工作交给机器，让人少熬夜；保持学习，紧跟技术演进。
