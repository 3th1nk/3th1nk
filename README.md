## 关于我

一个在后端领域深耕多年的开发者，偶尔也会跑到前端写写 Vue（虽然 CSS 还是会让我头疼）。主要使用 Go 构建高性能服务，有着 C/C++ 的底层开发经验，关注系统可观测性、自动化运维和云原生技术。

曾在医疗器械领域开发过心电图软件，也在物联网行业深度参与过扫地机器人和智能音箱的研发。从基于 ROS/MQTT 的机器人通信架构、WebRTC 音视频通讯，到激光雷达+视觉融合的 SLAM 导航方案；从嵌入式开发，到对接 AWS Alexa、Google Assistant、天猫精灵等智能音箱平台...这些跨领域的经历让我对实时数据处理、嵌入式系统和边缘计算有了更深的理解。

最近对 LLM 和 AI 技术产生了浓厚兴趣，正在探索如何将大语言模型应用到智能运维场景中。从基础的脚本生成和日志分析，到构建知识库 RAG 系统、设计 AI Agent 工作流，再到多智能体协作（Multi-Agent）和工具调用（Function Calling）——这些前沿技术正在重塑运维自动化的边界。

致力于通过技术手段提升运维效率和系统稳定性，同时也在不断学习新技术，保持对技术的热情和好奇心。
